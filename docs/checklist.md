## 图1 登录页 → views/login/index.vue
- 核心元素：淡蓝渐变+稀疏点阵背景；居中白色大圆角卡片；医院图标（圆形蓝色底）；标题"医院管理系统"；浅蓝副标题胶囊"一站式医院管理平台"；"欢迎登录"；带图标的账号框（admin）与密码框；勾选"记住密码"；蓝色渐变"登录"按钮。
- 交互：账号/密码校验（admin/123456）；密码可见切换；记住账号与勾选状态（不存真实密码）；登录 loading；错误提示；登录成功进入首页；窄屏卡片完整。

## 图2 首页 → views/dashboard/index.vue
- 核心元素：深色侧栏+白色顶栏+面包屑+可关闭标签页；四张指标卡：今日门诊、在院患者(待入科/在院/待结算)、空闲床位(可立即办理入院)、收费金额(今日收费)；"近七日门诊与收费"图（人次走柱、金额走线、双轴对照，浅蓝柱 #A4D0EA、深蓝线 #2F78BF）；"床位占用"环图（25% 当前占用，图例在院/空闲/已出院）；"待办闭环"（待执行住院医嘱/待发药处方/今日收费 ¥0.00 门诊收费合计）；"快捷入口"（门诊挂号/建档分诊/门诊接诊/医生接诊等图标入口）。
- 交互：数据全部由 Mock 数据层实时计算；图表 resize 自适应与销毁；快捷入口跳转对应页面。

## 图3 员工管理 → views/basic/StaffList.vue
- 核心元素：筛选（员工姓名/账号状态/员工类型/所属科室/登录账号）+ 搜索/重置；工具栏 +新增 / 删除 / 导出；表格列：工号/姓名、员工类型、所属科室、联系电话、登录账号、账号角色、账号状态（开关）、最后登录、操作（修改/重置密码/删除）；分页（共7条/10条每页/前往N页）。
- 交互：多选+批量删除确认；账号唯一校验；启用开关实时生效；导出当前筛选 CSV；删除被排班/挂号引用的员工给出提示。

## 图4 床位管理 → views/basic/BedList.vue
- 核心元素：筛选（所属病区/床位号/床位类型/床位状态/启用状态）+ 搜索/重置；工具栏 +新增 / 删除 / 导出；表格列：所属病区、床位号、床位类型(加床)、床位状态(空闲/占用)、启用状态(正常)、备注、操作(修改/删除)；示例数据：内科一病区 A01/A02、外科一病区 B01/B02。
- 交互：CRUD+校验；占用床位禁止删除；与入院登记联动（占床/释放）；状态标签颜色（空闲绿/占用红）。

## 图5 患者档案 → views/patients/PatientList.vue
- 核心元素：筛选（患者编号/患者姓名/联系电话）+ 搜索/重置；+新增；表格列：患者编号、患者姓名、性别、联系电话、过敏史、状态、操作(修改/删除)；示例数据：P00000000001000 林雪梅 女 13600000001、张文博、黄可欣、周启航、郑思怡、张强，过敏史：头孢类/青霉素。
- 交互：编号唯一；必填校验；CRUD；分页边界（末页删除回退）。

## 图6 医生排班 → views/outpatient/ScheduleList.vue
- 核心元素：日期范围（2026-08-17 至 2026-08-21）+ 查看周次 + 刷新排班；按科室的卡片网格（内科 D001、外科 D002、儿科 D003、急诊科 D004、检验科 D005、影像科 D006、住院处 D007…），每张卡片：科室名+科室编号、本周排班 N、出诊医生 N、查看详情、排班按钮。
- 交互：同医生同日同时段冲突不能提交；排班弹窗（医生/日期/时段）；日期范围联动统计；挂号只允许有排班的医生。

## 图7 门诊挂号 → views/outpatient/RegistrationList.vue
- 核心元素：筛选（挂号编号/患者姓名/科室/状态）+ 搜索/重置；工具栏 +新增 / 退号 / 导出；宽表列：挂号编号、患者、联系电话、就诊日期、时段(上午/下午)、科室、医生、挂号费(15)、挂号状态(待分诊/已完成/退号)、收费状态(已缴费)、操作；分页。
- 交互：新增挂号选患者→科室→(该日期+时段有排班)医生，费用自动；退号（未接诊可退、已缴费自动生成退费记录）；退号后不可接诊；导出 CSV。

## 图8 门诊接诊（弹窗） → views/outpatient/VisitList.vue
- 核心元素：接诊列表（状态筛选、+接诊按钮、表格）；大尺寸白色弹窗+半透明深遮罩：字段——挂号记录(选择待接诊挂号)、接诊状态(就诊中)、是否住院(否/建议住院)、主诉、现病史、诊断、处理意见；下方"处方明细"表（药品/用法/数量/金额/操作，+添加药品）与"医技申请"表（检验检查项目/数量/金额/操作，+添加项目）；底部 确定/取消。
- 交互：动态增删明细行；数量为正整数、价格有效性校验；金额自动汇总（整数分）；保存后挂号状态联动为已完成；长内容滚动且底部按钮可达；退号记录不可接诊。

## 图9 入院登记 → views/inpatient/AdmissionList.vue
- 核心元素：筛选（住院号/患者姓名/住院状态）+ 搜索/重置；工具栏 +新增登记 / 入科确认 / 转科转床 / 取消登记 / 导出；宽表列：住院号、患者姓名、性别、联系电话、病区、床位、预交金额、住院状态(待入科/在院/待结算/已出院)、操作(详情/入科/转床/取消)；示例：ADM… 周启航 内科一病区 A02、郑思怡 已出院 A01；分页。
- 交互：登记分配空闲床位；同一床位不可两人占用；转床同时释放原床位+占用新床位；取消登记释放床位；出院结算释放床位；状态与床位数据联动；导出 CSV。
